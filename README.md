# أداة بلاغات الصحة العامة
Public Health Notifications Tool

**آخر تحديث:** 26 أكتوبر 2026 — إعداد: د. حوراء الخليفة، إدارة مكافحة العدوى بالقطاع الشرقي
**الرابط الحالي:** https://hawraalkhalifah-star.github.io/Notifications-and-isolation-tool-/

## المحتوى
اختيار المرض ← البلاغ المطلوب (وقته، طريقته، المُبلِّغ، الشروط) ← الإدارات المعنية في وقاية (الإصحاح البيئي، نواقل الأمراض، التسممات، البرنامج الوطني للإيدز) ← نوع العزل ← توصيات وزارة الصحة ← CDC.

## المراجع
1. وزارة الصحة – قائمة الأمراض والأحداث الواجب الإبلاغ عنها، 2023: https://www.moh.gov.sa/Documents/list-of-notifiable-diseases-KSA-2023.pdf
2. وزارة الصحة – دليل الإجراءات الوقائية للأمراض المعدية، 2024: https://www.moh.gov.sa/Ministry/Rules/Documents/Communicable-Diseases-Guidelines.pdf
3. وقاية – قائمة أمراض مسار تفعيل فرق الاستجابة السريعة لمكافحة العدوى، 2026.
4. CDC – Appendix A (آخر تحديث 11 سبتمبر 2026).
